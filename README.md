## 目录结构

```text
books/
└── <book-slug>/
    ├── README.md          # 版本信息、阅读状态和本书导航
    ├── source/            # EPUB、PDF 等原文件
    └── notes/
        ├── notes.md       # 自己的理解和随读笔记
        └── questions.md   # 待解答与已解答的问题
```

## 记录约定

- 一本书使用一个目录，目录名采用简短、稳定的小写英文 slug。
- 原文件放在 `source/`；笔记和疑问使用 Markdown，便于搜索和比较修改。
- 在笔记中引用原文时注明章、节、幕、场或电子书位置，并与自己的想法分开写。
- 疑问使用任务列表维护：`[ ]` 表示待解答，`[x]` 表示已有结论。
- 日期统一写成 `YYYY-MM-DD`。
- 引用外部资料时记录作者、标题和链接，方便日后核对。

> 如果仓库将设为公开，请先确认 `source/` 中电子书的传播授权；不确定时只提交允许公开的引用和个人笔记。
